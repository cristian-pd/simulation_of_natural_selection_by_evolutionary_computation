# Bachelor's Thesis Project

This repository contains the code for the project I developed as my Bachelor's thesis in Computer Science. It is a Simulation of natural selection by evolutionary computation.

The repository contains only a Unity project. If you want to try it, simply clone the repository and open the project directory in Unity. Then, in the editor, open the scene located at `Scenes/GeneticAlgorithm`. After that, press Play in the Unity Editor to run the simulation. You will see the simulation in the Scene window.
